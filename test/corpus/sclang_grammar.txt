:error
==================
f = { |a|-1 };

==================
A pipe with an operator character after it is an operator: before a comment
:error
==================
f = { |a|/*c*/ a };
---



==================
A pipe with an operator character after it is an operator: two pipes
:error
==================
f = { || 1 };
---



==================
An equals sign with an operator character after it is an operator: between pipes
:error
==================
f = { |a=-1| a };
---



==================
An equals sign with an operator character after it is an operator: in an arg list
:error
==================
f = { arg a=-1; a };
---



==================
A default between pipes is a literal or in parentheses: a name is neither
:error
==================
f = { |a = b| a };
---



==================
A default between pipes is a literal or in parentheses: a sum is neither
:error
==================
f = { |a = 1 + 2| a };
